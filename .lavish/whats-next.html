Mobile · Your selected direction

Find and save People

Today, the apps search names already downloaded to your device. To add someone else, you need their internal Person ID.

The next slice adds an online search of your Organization by name or exact email/phone. Choose a Person, tap Save offline, and let the existing download process finish.

A search result is only a preview. The app shows “Available offline” after the complete record is safely saved.

Migration · The next history step

Earlier context, preserved

Core details, tags/custom fields, and notes/tasks are already deployed. Next comes historical events, calls, and text-message metadata for People added through later imports.

An administrator reviews saved source evidence, checks the gaps, then confirms which qualified records can be attached.

We preserve the source’s date labels. Old imported calls do not count as new calls made in this CRM.

What happens when something goes wrong?

The connection drops

Your request to download stays saved. The app waits for a valid connection and continues. A partial download never appears complete, and existing notes or edits stay protected.

If the Person is no longer available, you can cancel that download request without deleting your other saved work.

The source is uncertain

Conflicting or unlinked records stay visible for review. The import does not guess which Person they belong to or silently create duplicates.

If you cancel an import, completed records stay. A new confirmed attempt can finish exactly the work that had not yet been processed.

How we would build the pair

  1. Review the two specifications. Check the search/download rules and the history source, identity, and recovery rules.
  2. Accept the proposed contracts. These are the agreed shapes and rules shared by the server, apps, and stored data.
  3. Build the mobile server support alongside migration. Once the mobile interface is verified, iOS and Android can continue while migration work proceeds.
  4. Verify real workflows. Exercise interrupted downloads, offline restart, duplicate imports, cancellation, and correct history placement using isolated synthetic data.

Mobile search uses an operational workspace. Imported workspaces stay under administrator review, so mobile progress does not depend on activation.
